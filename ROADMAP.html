Economy support scope

Decided
Done
Immediate financial support

Players can send $500, $1,000, or $5,000 from their own wallet to an active ally through Diplomacy.

Removed
No building ownership transfer

Shared control already lets allies operate buildings and construct an economic base for one another after sending funds. Ownership transfer duplicated that workflow while introducing power-grid, collector, science, garrison, airfield, tunnel, upgrade, and defeat-state edge cases.

Current design decision
Transfer funds, not ownership. The recipient can use the money directly, while either ally can use shared control to build and manage infrastructure belonging to the recipient.

Next feature candidates

Investigating
Research
Attack move by value

An attack move that prefers the most valuable target in reach instead of the nearest. The engine already ranks targets by a priority table minus a distance penalty (one point per 100 units), but only for script-assigned AI teams; every unit's BuildCost can supply the value.

Test
Run-over move

A button (no key yet) on ground vehicles that can crush, dozers and supply trucks included: a move on which the unit swerves at enemy soldiers and any vehicles it can crush, within 110 of itself, never back the way it came, for at most 170 or 5 seconds per swerve, then rejoins its path. Painted button with a red border and a tank-track cursor; on ShockWave's China Dozer it sits on the One Down page. Stop or any order ends it. Crushing follows the data (CrusherLevel against CrushableLevel).

Idea
Hold Ground stance

A per-unit toggle: fire at anything in range but never move on its own (no retaliation chase, no pursuit), so chosen units cannot be lured away while Retaliation stays on for the rest.

Idea
Auto-retreat to repair

Badly damaged vehicles head back to a repair point on their own, like pilot auto-return.

Planned
Aircraft area strike and artillery barrage

Area commands that spread fire across a player-drawn area. Design work in progress.

Decision
Shorter retaliation chase

The occasional unit chasing deep into enemy lines is Zero Hour's own Retaliation option (confirmed by playing with it off). Option: cap how far a retaliating unit may leave its spot.

Networking and remaining issues

Planned
Done
Shared control over the internet through Radmin VPN

Matching clients completed a shared-control match across separate physical networks, with one PC on cellular data. Both games were bound to their Radmin addresses and used the Network lobby.

Done
Optional mixed allied transports and garrisons

A host-controlled Allow Mixed Allied Garrisons option gates shared passenger vehicles, shared garrison space, and allied-pilot promotion. It is on by default and synchronized to every client. Owned structures keep their owner's flag; civilian garrison leadership passes only when the current leader has no occupants left. Verified on two PCs.

Current
Restore a fully green GenCI build matrix

The tested modern Win32 Zero Hour builds pass. Legacy VC6 Zero Hour builds fail on the empty two-dimensional transfer-button initializer in Diplomacy.cpp; original Generals builds fail because shared Core UI code references the Zero Hour-only shared-control setting and two-argument GUI-command API. Keep both games and the historical compiler targets compatible, then rerun GenCI.

Planned
C&C:Online match verification

Windows 11 reaches Generals Online and both accounts entered a lobby. Full peer mesh/start still needs testing with a second suitable Windows 11 PC; Windows 8.1 compatibility remains problematic.

Low priority
Allied control-group number badge

Allied control groups select and receive commands correctly, but the group number is only drawn for locally owned units.

Done
Shared-control selection polish

Each client starts with its own Command Center selected, and allied controlled vehicles now draw passenger and ammunition pips.

Observe
Computer B slowdown

Compare a long, high-unit-count match with and without transfers. Transfer messages do no continuous simulation work, so older hardware or match load is currently more likely than the feature.
